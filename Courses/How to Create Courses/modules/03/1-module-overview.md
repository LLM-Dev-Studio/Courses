# Module 3 Overview: Contributing via GitHub

This module covers how course content actually reaches the live site now that it runs on Vercel instead of only on your own machine.

## Outcomes

- Understand why direct changes to `main` are no longer the workflow
- Branch, commit, and open a pull request for a course change
- Know what a reviewer checks before approving
- Confirm a merged change deployed successfully

## Key Takeaway

Publishing a course change is a GitHub pull request, not a local file save.
