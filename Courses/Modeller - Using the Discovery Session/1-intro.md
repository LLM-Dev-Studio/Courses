# Welcome to Modeller: Using the Discovery Session

A Discovery Session turns a raw change request into a recorded Initiative,
without assuming that the first proposed solution is the right one. This
course teaches you how to run that session as a Facilitator, from opening the
Initiative at [modeller.website](https://modeller.website) to finalizing it
or handing it to System Design.

This is an independent course about Modeller — it is not part of the
Modeller product itself. Every step below links to the live site or docs you
will actually use.

## What You Will Learn

- What an Initiative is, and the three roles that take part in a session
- How to open an Initiative and bring in a Domain Expert
- How to run the Discover and Frame question loop
- How to read and use the Discovery Gate and the Shape Gate
- How to compare interventions in Shape, and finalize or hand off an Initiative

## Where to Go

- Run a session at [modeller.website](https://modeller.website)
- Read the full docs at [modeller.wiki/docs](https://modeller.wiki/docs)
- Try the modelling playground at
  [modeller.website/playground](https://modeller.website/playground)

## Key Takeaway

A Discovery Session records the reasoning from a change request to a chosen
response — it does not skip straight to building what was first asked for.
