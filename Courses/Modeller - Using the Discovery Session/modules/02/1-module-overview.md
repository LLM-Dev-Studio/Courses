# Module 2 Overview: Starting a Discovery Session

This module covers the practical steps that open an Initiative: getting
ready, creating it at [modeller.website](https://modeller.website), and
bringing in your Domain Expert.

## Why This Matters

A session that starts poorly wastes the Domain Expert's time and produces a
weak record. A little preparation before you open the browser makes the rest
of the session run smoothly.

## What You Will Cover

- What to have ready before you start
- Creating the Initiative at modeller.website
- Sending the Domain Expert their link

## Where to Go

- [modeller.website](https://modeller.website) — start your Initiative here
- [Start a Discovery Session](https://modeller.wiki/docs/getting-started/start-a-discovery-session)
  — the full reference walkthrough this module is based on

## Key Takeaway

Discovery happens entirely in the browser at modeller.website — no install,
no account, and nothing to configure before you begin.
