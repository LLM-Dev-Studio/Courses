# Create the Initiative

With the change request and a Domain Expert ready, you can open the
Initiative.

## Fill In the Landing Page Form

Go to [modeller.website](https://modeller.website) and fill in the form on
the landing page.

| Field | What to put in it |
| --- | --- |
| Original change request | The request verbatim |
| Facilitator name | You |
| Domain Expert name | The person you are about to invite |

Select **Start the Initiative**.

## Land on the Facilitator Cockpit

You land on the Facilitator cockpit at `modeller.website/initiative/<id>`.
This is where you will run the whole session: proposing questions, watching
answers arrive, checking gates, and shaping the response.

> [!IMPORTANT]
> Bookmark that URL. There are no accounts, so the cockpit link is the only
> way back into your Initiative. If you lose it, you lose your way back in.

## Practical Steps

1. Open [modeller.website](https://modeller.website).
2. Enter the change request, your name, and the Domain Expert's name.
3. Select Start the Initiative.
4. Bookmark the cockpit URL immediately.

## Key Takeaway

Starting an Initiative takes one form and no account — but the resulting
cockpit link is the only way back in, so save it right away.
