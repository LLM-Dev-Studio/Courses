# Module 5 Overview: Finalizing and Handoff

This final module covers how to close out an Initiative, and what happens
when it selects a technology intervention.

## Why This Matters

Finalizing is not the same as deleting or forgetting. An Initiative stays
reachable after it closes, and a technology intervention carries its reason
forward into System Design.

## What You Will Cover

- Finalizing an Initiative, and reopening it later
- What carries forward into System Design
- What to watch for the first time you run a real session

## Where to Go

- [Quick start](https://modeller.wiki/docs/getting-started/quick-start) —
  where System Design picks up after a handoff
- [The playground](https://modeller.website/playground) — try System
  Design's modelling without an Initiative at all

## Key Takeaway

Finalizing records the Initiative as it stands, and a technology
intervention hands off to System Design with its reasoning attached — not as
a fresh, unexplained requirement.
