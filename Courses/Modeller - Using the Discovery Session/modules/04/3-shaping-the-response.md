# Shaping the Response

In Shape, you compare interventions across a fixed taxonomy and select as
many as the outcome genuinely needs.

## The Fixed Taxonomy

Every intervention you consider falls into one of eight categories:

- Process
- People
- Organisation
- Policy
- Information
- Technology
- Experiment
- No action

## Ask the Domain Expert

Ask a broad question to surface options across the taxonomy, for example:

> What changes could improve this situation without assuming that new
> software is the only answer?

## Select and Mark Each Intervention

For each selected intervention, record:

- A **description** of the change.
- A **rationale** — why this intervention addresses the framed outcomes and
  constraints.
- Whether it **continues into a design workspace**.

You can select several interventions at once. This supports mixed change,
such as removing an approval step, delegating authority, and automating a
document check, all against one shared outcome.

## Worked Example

In the variation-approval Initiative, the Facilitator records six
interventions:

- **Process** — a standard intake checklist for variation requests, because
  most rework starts with incomplete requests.
- **People** — a named variation coordinator per build, so requests have a
  clear owner.
- **Policy** — defined approval limits and a rule against unauthorized work
  starting.
- **Information** — a weekly variation-ageing report, so delays become
  visible to managers.
- **Technology** — a mobile-friendly shared variation register, marked to
  continue into System Design.
- **Experiment** — a four-week trial of the checklist, coordinator role, and
  register on two builds, to test the key assumptions first.

**No action** is considered and recorded, but not selected — the team notes
that it leaves the delay, evidence, and ownership problems unchanged.

> [!TIP]
> Considering "no action" explicitly, even when you reject it, is part of a
> healthy Shape phase — it shows the team weighed doing nothing against doing
> something.

## Key Takeaway

Shape compares real alternatives against the framed outcomes — select every
intervention the outcome needs, not just the one originally requested.
