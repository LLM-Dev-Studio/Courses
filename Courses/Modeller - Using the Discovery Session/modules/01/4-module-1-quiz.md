questions:
  - prompt: What is an Initiative?
    options:
      - A separate Business Problem Brief document
      - One growing structured record from change request to selected response
      - A commitment to build a specific piece of software
      - A form the Domain Expert fills in alone
    answer: One growing structured record from change request to selected response
    explanation: Discover, Frame, and Shape all update the same structured record — there is no second document to keep in sync.
  - prompt: What does Capture Request preserve, and why?
    options:
      - A tidied problem statement, so it reads more professionally
      - The original change request word for word, so it stays separate from the problem
      - The Domain Expert's job title, for the record
      - The chosen intervention, before Shape begins
    answer: The original change request word for word, so it stays separate from the problem
    explanation: Keeping the raw request separate stops it from being mistaken for the problem statement.
  - prompt: What can the Domain Expert see during the session?
    options:
      - Every question the Facilitator is drafting, plus gate findings
      - The full intervention comparison from Shape
      - The change request and the one question currently waiting for them
      - Nothing until the Initiative is finalized
    answer: The change request and the one question currently waiting for them
    explanation: The Domain Expert view is deliberately narrow so they can focus on what they are actually being asked.
  - prompt: What is true about the Agent Participant role?
    options:
      - It is required for every Initiative
      - It can propose questions or interventions, but never decides what enters the record
      - It replaces the Domain Expert when nobody is available
      - It automatically accepts responses on the Facilitator's behalf
    answer: It can propose questions or interventions, but never decides what enters the record
    explanation: AI is a pluggable adapter in this workflow, never a hard dependency, and the Facilitator always makes the final call.
