# The Question Loop

The cockpit's Discover & Frame section drives the whole conversation with one
repeating loop.

## The Four Steps

1. **Pick a field.** Choose the field you are trying to fill — problem
   statement, affected people, desired outcomes, constraints, and so on — and
   propose a question against it. Leave the question text blank to have the
   configured agent advisor suggest one. This is optional, and never
   required.
2. **Send to Domain Expert**, or reject the question if it is not worth
   asking.
3. **They answer.** The Domain Expert answers in their own view. The answer
   arrives back in the cockpit.
4. **Accept the response** to draft it into the structured field.

Repeat this loop for every field you need to fill.

## The Phase Indicator

As fields fill in, the phase indicator moves through Capture Request, Clarify
Problem, Identify Impact, Define Outcomes, and Set Boundaries. Both the
cockpit and the Domain Expert view update live, so you can run the loop in a
call or asynchronously over days.

> [!TIP]
> You decide which questions get asked and in what order. Nothing stops you
> from returning to an earlier field later if a new answer changes what you
> need to know.

## Practical Steps

1. Choose the next field to fill.
2. Write a question, or leave it blank for a suggested one.
3. Send it, or reject it if it is not worth asking.
4. Read the Domain Expert's answer when it arrives.
5. Accept the answer to draft it into the record.

## Key Takeaway

Every field in Discover and Frame fills in through the same loop: propose a
question, send it, read the answer, accept it.
