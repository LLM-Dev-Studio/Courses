# Module 3 Overview: Running Discover and Frame

This module covers the repeating loop that drives most of a Discovery
Session, and how that loop fills in the Discover and Frame fields.

## Why This Matters

Discover and Frame are where the session earns its value. A well-run
question loop turns a vague request into a problem statement, outcomes, and
boundaries the whole team can trust.

## What You Will Cover

- The question loop: propose, send, answer, accept
- The Discover phase: Capture Request, Clarify Problem, Identify Impact
- The Frame phase: Define Outcomes, Set Boundaries

## Key Takeaway

Discover and Frame are driven by one repeating loop — pick a field, ask a
question, get an answer, accept it into the record — run as many times as the
situation needs.
